# Overview

[← Back to Docs Home](../README.md)

## Purpose

Overview documents provide high-level public orientation to the project's
purpose and broad architecture. They are intended to help readers understand
the problem Compass addresses before following implementation-specific paths.

## Authority

Overview documents are non-authoritative. Current source, tests, migrations,
accepted ADRs, current boundary notes, and stage closeout records govern exact
runtime behavior, vocabulary, and implementation status.

## Current Overview

- [Compass: Runtime Semantic Admission for Agentic State Mutation](compass_agent_era_overview.md)
  — public orientation to candidate actions, accepted authority, semantic
  admission, and the current-versus-target runtime boundary.

## Relationship to Other Documentation

- The root README is the repository entry point and project-level guide.
- Architecture notes describe system structure and component relationships.
- Boundary notes define current responsibilities and explicit non-goals.
- Semantic Admission case studies explain specific public governance problems.
- Research notes explore possible future systems or mechanisms without making
  implementation commitments.

An overview may summarize those documents, but it does not override them or
create new architectural authority.
